# 📘 Evaluating the Effectiveness of Open-Source LLMs for Multi-Domain Bengali Text Classification

This repository contains the code, datasets, and documentation for the research paper:

**“Evaluating the Effectiveness of Open-Source LLMs for Multi-Domain Bengali Text Classification with Zero-Shot and Few-Shot Prompting.”**

The project benchmarks six modern open-source Large Language Models (LLMs) on four Bengali text classification tasks.

---

## 🚀 Overview

This study evaluates the following six open-source LLMs:

- **LLaMA-3.2-3B**
- **Mistral-V3-7B**
- **DeepSeek-R1-8B**
- **Phi-4-14B**
- **Gemma-2-27B**
- **Qwen-2.5-72B**

Across four Bengali NLP tasks:

- **Sentiment Analysis**
- **Emotion Recognition**
- **Hate Speech Detection**
- **Fake News Detection**

Two prompting strategies were used:

- **Zero-Shot Prompting**
- **Few-Shot Prompting (5-shot)**
